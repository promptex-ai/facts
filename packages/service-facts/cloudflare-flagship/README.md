# cloudflare-flagship-facts

Machine-readable facts about Cloudflare Flagship. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `service-facts` under the sub-path `service-facts/cloudflare-flagship`, for example `readFacts('service-facts/cloudflare-flagship')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of Cloudflare Flagship. Product names are trademarks of their respective owners.
